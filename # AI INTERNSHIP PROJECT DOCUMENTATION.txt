Project 9: News Article Grouping

 1. Project Title

**News Article Grouping Using NLP and Machine Learning**

 2. Introduction

Every day, a large number of news articles are published on different topics such as politics, sports, technology, business and entertainment. Manually organizing these articles is time-consuming.

Natural Language Processing (NLP) and machine learning can automatically analyze article text and group similar articles together.

This project uses **TF-IDF** to convert text into numerical features and **K-Means clustering** to group similar news articles.

 3. Problem Statement

To develop an AI-based system that automatically groups news articles according to their textual similarity using Natural Language Processing and clustering.

 4. Objectives

* Collect news articles.
* Clean and preprocess text.
* Convert text into numerical representation.
* Apply TF-IDF.
* Group articles using K-Means.
* Identify important words in each cluster.
* Visualize the groups.

 5. Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* NLTK
* Matplotlib
* TF-IDF
* K-Means

 6. Workflow

**News Dataset → Text Cleaning → Preprocessing → TF-IDF → Feature Matrix → K-Means → Important Keywords → Visualization → Topic Interpretation**

## CODE 1: Create News Dataset

```python
import pandas as pd

data = {
    "article": [
        "The cricket team won the match after excellent batting",
        "The football team scored three goals in the final",
        "The government announced a new economic policy",
        "Stock markets increased after positive business news",
        "Artificial intelligence is changing technology",
        "New software technology improves computer performance"
    ]
}

df = pd.DataFrame(data)

print(df)
```

### Sample Output

```text
                                             article
0  The cricket team won the match after excellent...
1  The football team scored three goals in the final
2  The government announced a new economic policy
3  Stock markets increased after positive business...
4  Artificial intelligence is changing technology
5  New software technology improves computer perf...
```

---

## CODE 2: Convert Text Using TF-IDF

```python
from sklearn.feature_extraction.text import TfidfVectorizer

vectorizer = TfidfVectorizer(
    stop_words="english"
)

X = vectorizer.fit_transform(df["article"])

print("TF-IDF Matrix Shape:", X.shape)
```

### Output

```text
TF-IDF Matrix Shape: (6, 24)
```

This means six articles were converted into a numerical matrix containing 24 text features.

---

## CODE 3: Apply K-Means

```python
from sklearn.cluster import KMeans

kmeans = KMeans(
    n_clusters=3,
    random_state=42,
    n_init=10
)

df["Cluster"] = kmeans.fit_predict(X)

print(df[["article", "Cluster"]])
```

### Sample Output

```text
Article 0 → Cluster 1
Article 1 → Cluster 1
Article 2 → Cluster 0
Article 3 → Cluster 0
Article 4 → Cluster 2
Article 5 → Cluster 2
```

Possible interpretation:

```text
Cluster 0 → Business/Economy
Cluster 1 → Sports
Cluster 2 → Technology
```

---

## CODE 4: Display Important Words

```python
terms = vectorizer.get_feature_names_out()

for i, center in enumerate(kmeans.cluster_centers_):
    top_words = center.argsort()[-5:][::-1]

    print("\nCluster", i)
    print("Important words:")

    for index in top_words:
        print(terms[index])
```

## CODE 5: Visualize News Clusters

```python
from sklearn.decomposition import PCA
import matplotlib.pyplot as plt

pca = PCA(n_components=2)

X_dense = X.toarray()
reduced = pca.fit_transform(X_dense)

plt.scatter(
    reduced[:, 0],
    reduced[:, 1],
    c=df["Cluster"]
)

plt.xlabel("Component 1")
plt.ylabel("Component 2")
plt.title("News Article Clusters")
plt.show()
```

### Output

A 2D scatter plot displays the news articles as points. Articles belonging to similar clusters appear close to each other.

### Limitations

* TF-IDF mainly represents word frequency and does not fully understand meaning.
* Articles with similar words can be grouped incorrectly.
* The number of clusters must be selected.
* Complex language can reduce accuracy.
